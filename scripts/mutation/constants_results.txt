# Why the two requirement mutants are equivalent: typing lets `using` bind
# providers only into a function value, and lowering (executable.rs,
# `provision`) always wraps that value in a closure that provides them again
# at each call. A call gives the callee its caller's providers ahead of the
# ones it captured, so the providers a constant function captured are always
# shadowed and no program can observe them. Decoding still binds them, as the
# interpreter's constant does, so the two value models stay the same.
