# Decision Ledger

One line per decision that shapes the language or how it is built, newest
first. Each entry names who decided and where the detail lives. Specs and
tickets hold the full reasoning; this page is for scanning and overruling.

`User` means Byron decided directly. `Coordinator` means the implementation
coordinator decided under the standing instruction to settle minor details
from the philosophy and earlier decisions; any of these can be overruled.

| 2026-11-15 | A process that must own a value from its start, such as an accepted socket or a `Receiver`, starts with `Supervisor.start_handoff(running, Process.handoff_spec(body, capacity, shutdown_within), argument)`. The body takes `(Inbox<M>, A)`; the spec stays shareable (so `T4260` still applies and a module constant may hold it), has no name, and is never restarted, so its slot frees when it ends. A refused start returns `HandoffError.CapacityReached(argument)` or `Stopped(argument)`, handing the argument back. Rejected: letting a `Process.spec` body capture exclusive values (it would make `Spec` shareable only sometimes, and a refused start could not hand the socket back), and start-then-send (two steps, and the body's message type would have to include the start value). Chosen to match Erlang's `start_child` with arguments and a temporary restart. | Implementer (G28), advisor reviewed | `process-and-supervisor-static-contracts.md` Handoff starts |
