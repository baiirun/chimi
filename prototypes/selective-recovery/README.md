# Selective Recovery Prototype

> PROTOTYPE: this is throwaway syntax evidence, not supported Chimi code.

Compare caller-facing recovery forms while preserving inferred failure rows.
The prototype tests one-off handling, reusable composition, complete recovery,
and unchanged bubbling.

Run the interactive comparison:

```sh
python3 prototypes/selective-recovery/main.py
```

Print every comparison noninteractively:

```sh
python3 prototypes/selective-recovery/main.py --all
```
